# COVID-19 Exploratory Data Analysis (EDA)

## 📘 Objective
Analyze global COVID-19 data to find trends and insights using Python.

## 🧠 Skills Used
- Data Cleaning (Pandas, NumPy)
- Data Visualization (Matplotlib, Seaborn, Plotly)
- Exploratory Data Analysis (EDA)

## 📊 Key Insights
- USA, India, Brazil top in total cases.
- 2021 had highest infection peaks.
- Vaccination improved survival rates.

## 🧰 Tools
Python | Pandas | Matplotlib | Seaborn | Plotly
